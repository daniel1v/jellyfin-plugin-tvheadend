Channels are normally analyzed the first time somebody watches them, which costs that viewer a few seconds once. With this enabled the analysis happens during a channel refresh instead, one channel at a time, so playback can offer the right variants from the very first tune. Each analysis briefly occupies a tuner. Failures are skipped and never fail the refresh.
The profile the broadcast is received through. "pass" forwards it untouched and is what every channel description is taken from. Changing this discards all stored descriptions.
Offered alongside the broadcast for channels carrying MPEG-2 video, so clients that cannot decode it play H.264 without a Jellyfin transcode. A client that can decode MPEG-2 still receives the broadcast. Leave empty to offer none.
Discards every stored channel description so they are established again. Use after changing anything inside a TVHeadend profile: a changed schema or a changed native profile is noticed automatically, a change inside a profile is not.
Each channel being watched is written into a buffer of this size in a circle, so this is the whole disk cost of a channel however long it runs. It is also how far a client may fall behind the live edge, by pausing for instance, before it is moved forward. Around ten minutes of an HD broadcast fit into 512 MB. Note: Changing this requires a server restart.
