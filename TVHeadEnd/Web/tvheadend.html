Each channel being watched is written into a buffer of this size in a circle, so this is the whole disk cost of a channel however long it runs. It is also how far a client may fall behind the live edge, by pausing for instance, before it is moved forward. Around ten minutes of an HD broadcast fit into 512 MB. Note: Changing this requires a server restart.
Broadcast listings carry no pictures at all, so without this a recording is a blank tile and a guide entry has nothing beside it. The channel logo at least says which broadcaster the programme came from, and it never replaces artwork that does exist. On a recording it is letterboxed onto a poster rather than stretched. Turning this off stops it being published; anything that already took a logo keeps it until the artwork is forgotten below.

Recording artwork

Jellyfin gives a recording a picture only when it has none, so the first one it is given is the one it keeps. Use this after an upgrade that changed how artwork is published, or if a recording is showing a picture it should not: the pictures are forgotten and fetched again on the next listing. Live channels and guide entries do not need it; they correct themselves.
